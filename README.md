# 📝 Личный Telegram-бот заметок

Личный бот для заметок с напоминаниями. Python + aiogram 3, PostgreSQL, Docker Compose, Long Polling (работает дома за NAT без открытых портов).

## Возможности

- **`/add <текст>`** — создать заметку. Можно сразу задать напоминание в свободной форме:
  - «купить хлеб **завтра в 9:00**»
  - «позвонить **через 30 минут**», «через 2 часа», «через 3 дня», «через неделю», «через полчаса»
  - «**понедельник 14:00**», «**сегодня в 18:30**», «**послезавтра 7:05**»
- **`/list`** — все заметки (с отметкой напоминания ✓⏰ / ⏰ и повтора 🔁).
- **`/delete`** (`/del`) — удалить заметку по inline-кнопке с подтверждением.
- Фоновая задача каждые 30 сек проверяет БД и шлёт созревшие напоминания.
- Напоминания, «просроченные» на момент запуска бота, отправляются с опозданием, но не позже чем через 24 ч (более старые молча пропускаются).

## Быстрый старт

1. Создай бота у [@BotFather](https://t.me/BotFather) и получи `BOT_TOKEN`.
2. Скопируй конфиг и впиши токен (и опционально свой `OWNER_ID` для ограничения доступа только тебе):
   ```bash
   cp .env.example .env
   nano .env
   ```
   `OWNER_ID` можно узнать у [@userinfobot](https://t.me/userinfobot); если оставить пустым, бот отвечает всем.
3. Собери и запусти:
   ```bash
   docker compose up -d --build
   ```
4. Логи:
   ```bash
   docker compose logs -f bot
   ```
5. Остановка:
   ```bash
   docker compose down
   ```

## Структура

```
bot/
  main.py        — запуск, Dispatcher, планировщик
  config.py      — чтение .env (токен, DSN, TZ, OWNER_ID)
  db.py          — asyncpg-слой и схема notes
  handlers.py    — команды /add /list /delete + inline-кнопки
  timeparser.py  — парсинг времени напоминания из текста
  scheduler.py   — фоновая задача отправки напоминаний
docker-compose.yml
Dockerfile
.env.example
```
